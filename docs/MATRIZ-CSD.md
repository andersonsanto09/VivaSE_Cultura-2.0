# Matriz CSD — VivaSE Cultura

Versão inicial: 16/11/2026. Etapa do ideathon: mapeamento de problemas e Matriz CSD, na orientação metodológica de Design Sprint.

Desafio: ajudar turistas que não conhecem São Cristóvão a se orientar durante o FASC.

| Certezas | Suposições | Dúvidas |
| --- | --- | --- |
| O projeto terá um protótipo para apresentação. | Turistas têm dificuldade para encontrar palcos e serviços durante o FASC. | Quais dificuldades são mais frequentes para os visitantes? |
| O público prioritário escolhido pela equipe são turistas que não conhecem São Cristóvão. | Um mapa com localização e programação ajudaria na orientação. | Como os turistas se orientam atualmente? |
| A equipe possui um conceito anterior, prints e pitch. | História, memórias e roteiros podem enriquecer a visita. | A conexão de internet permite usar o mapa durante o festival? |
| Há programação oficial e fontes históricas disponíveis para pesquisa. | Uma área administrativa seria útil para a organização. | Quem forneceria e atualizaria as informações? |

## Como validar

Entrevistar visitantes e organização; observar tarefas de orientação; testar o fluxo do protótipo sem conduzir as respostas. Registrar contexto, data, método e evidências. Uma hipótese só muda de coluna após evidência suficiente para a afirmação específica.

Escolher o público é uma decisão da equipe. Não equivale a comprovar as dificuldades desse público. O PDF preserva esta matriz inicial; futuras revisões precisam atualizar a versão em texto e a versão exportada de forma coerente.
