# Participações artísticas documentadas no FASC — pesquisa para o VivaSE

**Aviso de evidência:** `programado` significa que o nome aparece em programação publicada, não que o show necessariamente aconteceu. `apresentação realizada` / `participação documentada` só foram usados quando existe cobertura posterior. Para 1972, a fonte é uma programação antecipada publicada em julho de 1972.

## Instruções para o Codex

1. Importar as `participacoes`, deduplicando artistas por nome normalizado, mas preservando uma participação por edição e linguagem.
2. Não confundir nome de palco com presença do homenageado (e.g. Gal Costa).
3. Não transformar programação em prova de realização.
4. Não criar marcador geográfico sem localização documentada e validada; local textual pode ser exibido em card.
5. Cármen Lúcia consta como participação remota. Lia de Itamaracá consta como convidada de Héloa.
6. Essa lista é curada: pesquisar o restante das programações para cobertura completa.
